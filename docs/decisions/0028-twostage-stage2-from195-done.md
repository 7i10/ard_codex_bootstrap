## 選択肢

### A: 足さずに残り3本を待ち、2段階学習パイロットを閉じる（推奨）

- **内容**: 新しい GPU の run は入れない。from100 と Ferret の2本の postrun を順に行い、4本すべてに同じ事前登録ルールを当てる。
- **GPU時間**: 追加 0（残り3本はすでに走っています）。
- **分かること**: 2段階学習（今の stage 2 の設定）が、stage 1 の長さ（195 / 100 / 50 epoch）と S=256 か元画像かによらず、単一段階より低いかどうか。
- **事前登録ルール**: 各 stage 2 の最後の epoch の PGD-10 を 30.71 と比べる（+1pt 以上=良い、±1pt=同等、−1pt 以下=悪い）。
  4本すべて「悪い」なら、2段階学習は今の設定では採らず、フル AT 50 epoch を Phase 1 の基本とする。
  どれか1本でも「同等」以上なら、その1本について seed を足すかを新しい packet で決める。
- **リスク**: Ferret の2本の待ち時間。stage 2 の lr（0.0025）を一つしか試していないので、「lr の選び方が悪かっただけ」という可能性は残ります。

### B: stage 2 の lr を 0.025 にした1本を足す

- **内容**: 195 epoch 版の last.pt から、lr 0.025（単一段階の基準のピーク lr）、ほかは同じ（20 epoch、2 epoch ウォームアップ、epoch 10 と 15 で 1/10）の stage 2 を Hamster GPU0 で回す。
  スケジュールの変更なので、**新しい科学的条件**として plan への追記と config のレビューが先に要ります。
- **GPU時間**: 約 7.5〜8.5 GPU時間（実時間も同じ）。config 作成とテストに少し。
- **分かること**: 今回 PGD-10 がほとんど伸びなかったのが、stage 2 の lr が低すぎたせいかどうか。
- **事前登録ルール**: 最後の epoch の PGD-10 を 30.71 と比べる（上と同じ ±1pt）。
  さらに今回の 28.45 より 1pt 以上高ければ「stage 2 の lr が効く」と書く。±1pt 以内なら「lr を10倍にしても変わらない」とし、2段階学習を閉じる。
- **リスク**: 結果を見てから条件を変える「救済」の試みです。1 seed で、2本目の stage 2 の条件を選んだことになるので、
  当たっても「選んだ条件が偶然良かった」可能性が残ります。AdvXL も stage 2 は微調整（低めの lr）なので、今回の lr の選び方が不自然だったわけではありません。
  stage 1 の重みを大きく動かすので、2段階学習の「低解像度で安く学ぶ」意味が薄れる可能性もあります。

### C: Ferret の2本を止めて早めに閉じる

- **内容**: from50s256 / from50orig を今止める（ABANDONED と記録）。from100 の結果が出たら、from195 と from100 の2本だけで判定する。
- **GPU時間**: 追加 0。Ferret の残り時間（2本分、相乗りで遅いので数時間〜十数時間と見ています。進み具合は未確認）を節約。
- **分かること**: stage 1 の長さ 195 と 100 で結論が同じかどうか。S=256 か元画像かの問いは答えずに閉じる。
- **事前登録ルール**: from100 も「悪い」（29.71% 未満）なら、2段階学習は今の設定では採らず、S=256 対 元画像の問いは「2段階学習を採らないので不要」として閉じる。
  from100 が「同等」以上なら、止めた2本のうち from50orig を回し直すかを新しい packet で決める。
- **リスク**: Ferret の操作が要ります。from100 が意外に良かった場合、止めた run をやり直す手間が出ます。
  共有ホストの Ferret を早く空けられる利点はありますが、すでに走っている run を止めて得るものは小さいです。

## 推奨

A を勧めます。判定は事前登録ルールで明確に「悪い」で、どの epoch を取っても変わりません。
残り3本は追加の GPU 時間なしで走っており、from100 は約1時間で終わります。
4本そろえば「stage 1 の長さや前処理によらず悪いかどうか」まで、追加費用なしで言えます。
B は結果を見てから条件を変える救済で、1 seed では当たっても解釈が弱く、Phase 1 の本線（学習率グリッド）から GPU を取ります。
C は節約できるのが Ferret の数時間だけで、すでに走っている証拠を捨てます。
推奨が変わるのは次の場合です。from100 か Ferret の1本が 29.71% 以上に届いた場合（そのときは seed を足す packet を書きます）、
または、人間が「2段階学習は stage 2 の lr を1点しか試していないので、閉じる前に1回は lr を上げて確かめたい」と判断した場合（そのときは B）です。
