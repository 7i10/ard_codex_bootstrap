**事前登録ルールの判定（plan 0104 stage 1）**
- 主ルール：last PGD-10 が 31.59% 以上ならレシピ候補でした。結果は 31.26% で 0.33pt 足りません。**Arm A のままです。**
- 予算ルール：val PGD-10 が epoch 25 までに 30.58% に届けば「半分の予算の候補」でした。
  初めて届いたのは epoch 26（30.60%）です。epoch 25 は 30.44% でした。**1 epoch 遅れで、候補ではありません。**
- 解釈表：ランダム初期化・50 epoch は Arm A より −0.53pt、今回は +0.68pt で、どちらも 1pt 以内です。
  事前登録の読みは**「事前学習は必要ない」（n=1）**です。

わかったこと：
1. **PGD-10 の上乗せは小さいです。** Arm A より +0.68pt（seed 0 比）、+0.67pt（seed 1 比）です。1pt の閾値に届かず、ノイズの範囲内です。
2. **clean は大きく上がりました。** Arm A より +3.24pt（seed 0 比）、+3.48pt（seed 1 比）です。
   plan 0103 / 0104 のこれまでの比較で最大の差で、CIFAR で測ったノイズの上限（1.88pt）も超えています。
   ただしルールは PGD-10 だけを見ます。clean の差は報告するだけで、判定には使いません。
3. **事前学習の clean が守られています。** val clean は epoch 0 の 49.46% から一度も下がりませんでした。
   lr 0.005 区間では 51.8〜53.2% です。Arm A は lr 0.05 区間で約 37〜38% まで落ちていました。
4. **lr 0.005 区間は Arm A ほど平らではありません。** PGD-10 は 24.58% から 27.60% まで伸びました。ただし最後の 5 epoch はほぼ横ばい（26.99〜27.68%）です。
   最初の LR 減衰（epoch 25）で、PGD-10 は 1 epoch で +2.8pt 伸びました。
5. **最後の区間は飽和しています。** epoch 38〜49 で PGD-10 は 31.22〜31.39% の間にとどまりました。
6. **学習画像との差はランダム初期化と同程度です。** probe と val の差は clean +5.0pt、PGD-10 +5.2pt です。

## ノイズの大きさ

CIFAR で同じ設定を 2 回走らせたときの差は 0.16〜1.88pt でした。乱数だけで 1〜2pt 動く、というのがこのプロジェクトの目安です。
Arm A の 2 seed の差は PGD-10 で 0.01pt、clean で 0.24pt でした。ただし 2 本だけではばらつきの推定になりません。
- PGD-10 の差（約 0.7pt）はノイズの範囲内です。seed を 1〜2 本足しても判定できません。
- clean の差（約 3.2pt）はノイズの上限を超えています。seed を 1 本足せば「向きがそろうか」は言えます。大きさや母集団については言えません。

- **GPU 時間**：約 21〜23 GPU-h（4090 1 枚）。Hamster では stage 2 のキューのあとになるので、始まるのは早くても約 1〜2 日後です。

- **判定ルール（事前登録）**：seed 1 の last clean が 55.57%（Arm A の高い方 54.57% + 1pt）以上なら、「clean の上乗せは 2 seed で同じ向き（方向のみ）」とします。

- **リスク**：stage 2 で lr 0.015 の方が良ければ、lr 0.005 に seed を足した結果は Phase 1 のレシピ選びに直接は使われません。
  plan 0104 の stop rule により、seed の追加には人間の判断が必要です。この選択肢がその判断にあたります。

## 推奨

**A** を推奨します。
事前登録ルールの答えは「Arm A のまま」です。この結果だけで Phase 1 のレシピが変わることはありません。
事前学習の LR の選択は、すでに承認済みで動いている stage 2 が、同じ条件の 3 点比較で行います。
lr 0.015 の run が clean と PGD-10 をどう両立させるかを見てからの方が、seed を足す場所を正しく選べます。

判断が変わるのは次の場合です。
- stage 2 で、事前学習の各 LR の PGD-10 の差が 1pt 以内に収まった場合。そのときは clean が LR 選びの実質的な決め手になります。clean の上乗せを確かめる B（または同じ形で lr 0.015 に seed を足すこと）に意味が出ます。
- 研究の主張の中心を「clean を保ったまま頑健性を得る」（plan 0102 の方向）に置く場合。そのときは stage 2 を待たずに B で 2 seed にそろえる価値があります。
