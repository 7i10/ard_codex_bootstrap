## 選択肢

### A: 記録だけで閉じる（おすすめ）

- **GPU時間**: 0。
- **わかること**: 新しいことはありません。SE の効果は、どちらの活性化でも 0.5pt の線の近く（+0.41、+0.55。EMA では +0.64、+0.49）と記録します。
- **事前ルール**: Phase 2 のルールの「保留」は「2本目の seed で確かめる」ですが、この選択肢ではそれを行わず、「保留のまま採用しない」とこの packet の判断として記録します。SE は MobileNetV4-S の Phase 2 の標準に入れません。最終レシピの段階で SE を入れるかを改めて問う場合は、新しい packet と seed 2本以上で決めます。
- **リスク**: SE が本当に 0.5pt くらい効いているなら、それを逃します。ただし 0.5pt は、seed 2本でも決めきれない大きさです（下のおすすめの理由）。論文の表で「SE の効果」を書くときは、「seed 1本、境界」としか書けません。

### B: SiLU と SiLU＋SE の seed 1 を対で回す

- **GPU時間**: 約 40〜44 時間（SiLU 1本 約 19〜20.5 時間は SiLU の実測 19.34 時間から、SiLU＋SE 1本 約 20〜22 時間は ReLU の SE の実測 20.47 時間から。Hamster の 4090 を2枚並べて実時間 約 21〜22 時間）。0044 で C を選ぶ場合、SiLU の seed 1 はそちらで回るので、追加は SiLU＋SE の1本 約 20〜22 時間だけです。
- **わかること**: seed 1 でも SE が SiLU の上に足し算で効くか。同じ seed・同じホストの対なので、ホストの違いは外れます。
- **事前ルール**: seed 1 の対の差（SiLU＋SE − SiLU、どちらも seed 1、同じ Hamster、最後の普通の重み、取り分けた画像すべての PGD-10）が +0.5pt 以上 → 「2本とも保留以上で同じ向き」とし、SE を SiLU の上の候補として最終レシピの検討に残す。0 以上 0.5pt 未満 → 「効果なし」とし、SE は採用せずに閉じる。0 未満 → 向きが逆なので閉じる。2本の平均やばらつきは出しません。
- **リスク**: 期待される差（約 0.5pt）は、seed 1本ずつの対では揺れ（0.36pt の seed 差が2本分入る）に埋もれる大きさです。どちらの結果が出ても、「SE が 0.5pt 効く」かどうかは強くは言えません。40 時間以上を、決めきれない問いに使う可能性があります。

### C: SiLU＋SE の seed 0 を Hamster で回し直す

- **GPU時間**: 約 20〜22 時間（Hamster の 4090 1枚、ReLU の SE の実測から）。
- **わかること**: ホストの違いを外した SiLU＋SE − SiLU の差。Ferret の run との差は、同じ seed・同じ source でのホストの影響の大きさ（1組）にもなります。
- **事前ルール**: Hamster の SiLU＋SE − SiLU（33.27）が +0.5pt 以上 → 「保留」のまま（B か A をもう一度選ぶ）。0.5pt 未満 → 「効果なし」とし、SE は採用せずに閉じる。ホストの影響は、Hamster と Ferret の SiLU＋SE の差として記録だけします（判定には使いません）。
- **リスク**: seed は 0 のままなので、seed の揺れについては何もわかりません。「保留」が続いた場合、結局 B が必要になり、合計の時間が増えます。

## おすすめ: A

SE の効果は、ReLU で +0.41、SiLU で +0.55 と、どちらも 0.5pt の線のすぐそばです。EMA の重みでは向きが入れ替わり、ホストの違いだけでも線をまたぎうる大きさです。
この大きさ（約 0.5pt）は、seed を1本ずつ足しても決めきれません。MobileNetV4-S の seed の差（0.36pt）が対の両方に入るので、B の結果がどちらに出ても「SE が 0.5pt 効く」とは言い切れないからです。
一方で、SiLU の効果（+2.56）は SE を足しても残り（SE ありで +2.71）、研究の主な結論は SE の判定に左右されません。
SE は計算を増やし（携帯端末での推論の速さは測っていません）、CUDA Graphs も使えないので、決めきれない効果のために標準に入れる理由は弱いです。
GPU は、0044（SiLU を標準にするか）と 0054（100 epoch）のように、効果が「保留」以上ではっきりしている問いに回すほうが得るものが大きいと考えます。

**判断が変わる場合**:
- 0044 で C（SiLU の seed 1）を選ぶ場合 → SiLU＋SE の seed 1 は追加 約 20〜22 時間で対になるので、B の費用が半分になり、B を選ぶ価値が上がります。
- 論文の表に「SE の効果」の行をきちんと載せたい場合 → B（ただし、seed 2本では「同じ向き」までしか言えません）。
- ホストの違いそのものを測っておきたい場合（Ferret と Hamster の結果を今後も並べるため）→ C。

`chosen` は人間が記入します（ファイルを編集するか、チャットで答えてください）。記入されるまで、この packet に関わる新しい学習は始めません。

## 決定（2026-10-15、本人、チャットで回答。decision 0051 と同時）

**A を選択。** SE は採用しない。結論は「パラメータ数をそろえると SE の効果は小さい（ReLU で +0.41、SiLU で +0.56。+0.5 前後、1pt 未満）」で、「効果なし」とは断定しない。白黒をつけるための seed は「今は」足さない。理由：スマートフォンでの計算が遅くなる代償を払っても、大きな効果は得られないと考えるため。あわせて、特殊な部品（SE、SiLU/GELU、attention など）を足す変更はできるだけ避ける方針（discussion register、2026-10-15）。
