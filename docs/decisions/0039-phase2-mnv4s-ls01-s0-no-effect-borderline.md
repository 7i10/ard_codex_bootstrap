### A: いま「効果なし」で閉じる

## おすすめ: B

ルールは「効果なし」と言っていて、それを変える理由（C）は境界が近いことだけです。境界の近さは、ルールを決めたときに想定済みの状況です。
一方で、比較相手は別の source の Phase 1 の run で、設定チェックがまだ済んでいません。
B は追加の GPU 時間なしに、そのチェックを判定の前に入れられます。待ち時間の約 15 時間に、この件で GPU を使う予定はありません。
clean が下がっていて cosine より低いことも、seed 1 に 16 時間をかける（C）理由を弱めます。

**判断が変わる場合**: Ferret の MobileNetV4-S seed 1 が先に終わり、seed 0 と seed 1 の差がとても小さい（たとえば 0.2pt 未満）とわかれば、+0.45pt にも意味がある可能性が出てきます。その場合は C を考え直す価値があります。
また、他モデルでラベル平滑化を回すかどうかは、この packet の範囲外です。それは Phase 2 の候補の選び方の問題なので、別に決めます。
