## 選択肢

### A: ここで閉じる

- **GPU時間**: 追加 0。Ferret に EfficientNet-B0 の BN 分割版が残っていれば外すので、C の分（約 100〜140 時間）の節約になります。
- **わかること**: 新しいことは何もありません。「MobileNetV4-S では mixed batch（重み 0.3）は BN 共有でも BN 分割でも PGD-10 を 8pt 以上下げる」として記録します。
- **事前ルール**: すでに適用済みです（0041 B のルールで「効果なし」、Phase 2 のルールでは損の側の「効果あり」）。
- **リスク**: 重み 1.0 や他のモデルで結果が変わる可能性は確かめません。人間の 2026-10-11 の意見（「λ=1、攻撃の割合、BN 分割、エポック数で、頑健性を下げずに clean を上げる方向を検討する」）のうち、BN 分割だけを確かめて閉じることになります。

### B: 攻撃側の重みを 1.0 にした BN 分割版を MobileNetV4-S で1本回す

- **GPU時間**: 約 30〜45 時間（4090 1枚）。今回の 44.34 時間（Ferret、eager）を上限に、Hamster で他の job と重ならなければ速くなる分を下限に見ています。eager の速さを Hamster で測っていないので、幅を広めに取っています。
- **わかること**: 攻撃画像の損失を 23% から 50% に上げたとき、本体 BN のネットワークの PGD-10 がどこまで戻るか。今回の「保存したネットワークは目的関数が軽く扱っている」という読み方を確かめることにもなります。
- **事前ルール（いまここで固定します）**: 指標は最後の epoch・普通の重み・全取り分け画像の PGD-10。基準 30.71 に Phase 2 のルールを当てます: 32.21 以上 → 「効果あり」で mixed batch の線を続ける、31.21〜32.21 → 「保留」、31.21 未満 → 閉じる。clean は別に記録します。
- **リスク**: 重み 1.0 でも攻撃画像の割合は full AT の半分なので、基準を上回る見込みは低いと考えます。重みは Kurakin の設定（0.3）から外れる新しい候補なので、plan に新しい項目として書き、設定ファイルを1つ足してからになります。

### C: Ferret の EfficientNet-B0 BN 分割版（重み 0.3）を回す

- **GPU時間**: 約 100〜140 時間。EfficientNet-B0 の full AT は Hamster で 48.6 時間（Phase 1）、MobileNetV4-S の BN 分割版は full AT の約 2.9 倍（44.34 / 15.52 時間）かかったので、それを当てています。
- **わかること**: EfficientNet-B0 でも BN 分割の mixed batch が PGD-10 を下げるか。
- **事前ルール（いまここで固定します）**: 最後の epoch・普通の重み・全取り分け画像の PGD-10 を、EfficientNet-B0 の基準（baseline+EMA が終わっていればそれ、なければ Phase 1 の lr 0.025 の 35.93）と比べます。+1.5pt 以上 → 続ける、+0.5〜1.5pt → 保留、それ未満 → 閉じる。
- **リスク**: MobileNetV4-S で −8.25pt なので、EfficientNet-B0 で基準を 1.5pt 上回る見込みは低いと考えます。Ferret の GPU を長く使います（Ferret は共有なので長い job は避けたい）。キューにまだ残っているかを先に確かめる必要があります。

## おすすめ: A

Phase 2 の目的は PGD-10 を上げる学習の工夫を探すことです。mixed batch（重み 0.3）は BN 共有で −13.37pt、BN 分割で −8.25pt と、どちらも誤差の目安の 20 倍以上の損でした。BN 分割で 5pt 戻った分、clean を 15pt 失っており、clean と頑健性のどちらでも full AT に負けています。
B は今回の読み方を確かめられますが、攻撃画像の割合が full AT の半分である以上、基準を超える見込みは低く、30〜45 GPU時間は SiLU（0044）など効果が出ている候補の確認に回すほうがよいと考えます。C は同じ結論を別のモデルで確かめるだけで、費用が最も大きいです。

**判断が変わる場合**:
- 「頑健性を大きく落とさずに clean を上げる」方向を、PGD-10 を上げる候補とは別の目的として残したい場合は、B を選ぶ理由になります。その場合は評価する BN（本体か補助か）も plan で先に決めてください。
- clean と頑健性の交換の図を論文に載せたい場合は、すでにある2点（BN 共有 62.88 / 17.34、BN 分割 47.95 / 22.46）と基準で足りるかを先に見てください。足りなければ C か B が理由を持ちます。
