わかったこと：
1. **差の向きはそろっています。** 事前学習・50 epoch と比べて、ランダム初期化は PGD-10 で 0.53〜0.54pt、clean で 0.97〜1.21pt 低いです（last）。

2. **100 epoch にするとランダム初期化の不足はほぼ埋まります。** 50 → 100 epoch で、ランダム初期化は PGD-10 +0.53pt・clean +1.20pt 伸びました。

3. **再現性の確認がとれました。** epoch 0〜24 は、ランダム初期化・100 epoch の run と表示桁まで完全に一致しました（epoch 0：1.36 / 0.98、epoch 24：37.12 / 19.51）。

## ノイズの大きさ

Arm A の 2 seed の差は PGD-10 で 0.01pt、clean で 0.24pt でした。ただし 2 本だけではばらつきの推定になりません。
- PGD-10 の差（約 0.5pt）はノイズの範囲内です。seed を 1〜2 本足しても判定できません。
- clean の差（約 1.2pt）はノイズの下限あたりです。seed を足せば「向きがそろうか」だけは言えます。大きさまでは言えません。

## B：ランダム初期化・50 epoch に seed 1 を足す

- **GPU 時間**：約 21〜23 GPU-h（4090 1 枚）。stage 2 のキューのあとに置くので、始まるのは早くても約 2 日後です。
- **確定すること**：clean の差（約 1.2pt）が、seed を変えても同じ向きに出るか。2 seed なので方向だけで、大きさや母集団についての主張はできません。
- **判定ルール（事前登録）**：seed 1 の last clean が 53.33%（Arm A の低い方 54.33% − 1pt）以下なら、「clean の差は 2 seed で同じ向き（方向のみ）」とします。
  それ以外なら「clean の差は再現しない」とします。PGD-10 は並べて報告しますが、判定には使いません（0.5pt はノイズの範囲内）。
- **リスク**：lr 0.05 はランダム初期化にとって最適でない可能性があります。stage 2 がそれを調べている最中です。
  もし stage 2 で lr 0.1 や 0.025 の方が良ければ、lr 0.05 に seed を足した結果は、Phase 1 のレシピ選びには使われません。
  plan 0104 の stop rule により、seed の追加には人間の判断が必要です。この選択肢がその判断にあたります。
