## ノイズの大きさ

skill の目安「1〜2pp」は CIFAR-10 の e114 の話です。ここには当てはまりません。この
ImageNet の比較で使うのは、上に挙げた3つです。2本の差の標準誤差 0.43pt、

+1.18 はこの3つを超えています。ただし、どれも seed 0 の run 1本ずつの比較です。

## 選択肢

### A: EfficientNet-B0 を待って、4モデルそろってから決める
- **GPU時間**: 追加 0。すでに走っている run（EfficientNet-B0 は1本約 48 時間、
  ep 17 まで終わっている）の残り約 31 時間を待つだけです。
- **わかること**: 4モデル目の大きさ。C 案の判定そのものは変わりません。
- **事前ルール**: C 案と同じです。加えて、モデルごとの tier ルールで EfficientNet-B0 を読みます。
- **リスク**: C 案の結論が変わらないので、待つ間に得られるのは大きさの情報だけです。
  cosine を後の組み合わせ段階に入れるかどうかの判断が約 1.5 日遅れます。

### B: いま C 案を採用する（推奨）
- **GPU時間**: 追加 0。
- **わかること**: 事前に決めたルールで「cosine は seed 0 の3モデルで基準を
  +0.5pt 以上上回る」と言えます。どの seed、どのモデルでの話かを付けて述べ、
  母集団についての主張にはしません。0038 / 0052 / 0053 の問いもこれで閉じます
  （それらの packet はこの選択を参照して閉じる。0065 では書き換えない）。
- **事前ルール**: 0038 C（2026-10-09 時点で事前に書かれたもの）。4モデル中3つ以上で
  +0.5pt 以上なら「効果あり」、2つ以下なら「効果なし」。今は 3 / 3 です。
- **リスク**: 同じモデルで2本目の seed を回す確かめ方ではありません。どの比較も1本ずつで、
  source（MobileNetV4-S と ConvNeXt-Atto はホストも）が違うペアが含まれます。
  1モデルの差は「保留」の帯の中にとどまり、1.5pt に届いたものはありません。

### C: MobileNetV4-M の cosine seed 1 を1本回す
- **GPU時間**: 約 35〜37（Hamster の 4090 で、今回の 35.57 時間から見積もり）。
  Hamster のキューでは EfficientNet-B0 の後になります。
- **わかること**: seed のばらつきが一番小さいモデル（0.09pt）で、2本目の seed でも同じ向きになるか。
- **事前ルール**: d1 = cosine seed 1 − Phase 1 seed 1（63.71 / 39.30、Hamster、`609e6fa`）。
  d1 が +0.5pt 以上なら MobileNetV4-M で「効果あり」（seed 0 と 1 での向き）とします。
  +0.5pt 未満なら「効果は確認できない」とします。
- **リスク**: 比べる相手が Phase 1 の run なので、Phase をまたぐ弱点が残ります。
  seed 0 での大きさは −0.29pt でした。d1 が +0.5 の前後 0.3pt に出たときは決めにくくなります。

### D: MobileNetV4-M で cosine と基準＋EMA の seed 1 を両方回す
- **GPU時間**: 約 70〜74（Hamster で約 3 日。2枚使えば約 1.5 日。ただし GPU1 の空き次第）。
- **わかること**: Phase 2 の設定どうしの、きれいな seed 1 のペア。Phase をまたぐ弱点がありません。
- **事前ルール**: d1' = cosine seed 1 − 基準＋EMA seed 1。d0 = +1.18 と d1' が
  どちらも +0.5pt 以上なら「効果あり」（この2本の seed での向き）。
  どちらかが +0.5pt 未満なら「保留のまま」とします。
- **リスク**: いちばん高くつきます。同じ時間を、ほかの Phase 2 候補（ラベル平滑化、
  hard-swish など）に回せなくなります。

## 推奨の理由

推奨は **B** です。理由は2つあります。一つ目に、C 案は MobileNetV4-M の結果が出る前に書かれた
事前ルールです。その条件は今、EfficientNet-B0 の結果に関係なく満たされています。
このため A で待っても、このルールの判定は変わりません。二つ目に、4本とも同じ向きで、
大きさは +0.78〜+1.38 です。どれも、測れているノイズ（0.09〜0.43pt）を超えています。
EfficientNet-B0 は、B を選んでも約 31 時間後に記録され、大きさの情報として加わります。

推奨が変わる場合もあります。cosine を「1モデルで 1.5pt 以上」または「同じモデルの
2 seed」で確かめたいなら、B では足りません。その場合は C（安い）か D（きれい）です。
また、Phase 2 の後の段階で、cosine を他の候補と組み合わせる前提にするなら、
1モデルだけでも seed 1 で確かめる C の価値が上がります。
