# plan 0103 論点台帳（議論の決定・未決の一覧）

研究の方向（軽量モデルの ImageNet 敵対的学習）について、チャットで議論した論点を1か所にまとめる。
各論点に「状態（決定／未決）」「決めた日」「内容」を書く。
詳しい経緯と数値は plan 0103 / 0104 の Progress log を正とし、ここは索引として使う。
更新するときは、決定を上書きせず、新しい日付の行を足す。

## 研究の主張と位置づけ（A）

| ID | 論点 | 状態 | 日付 | 内容 |
|---|---|---|---|---|
| A1 | 論文の主な主張 | 決定 | 2026-09-28 | 軽量モデルごとに、パラメータ数・計算量あたりの頑健性を示す。あわせて、それぞれに合う学習法（事前学習の要否を含む）を示す。学習不足になる場合は、その理由と対策も示す。RQ1 は効率（パレート図）、RQ2 はモデルごとの処方、RQ3 は学習不足の仕組みと対策。 |
| A2 | 公平な比べ方 | 方針は決定、具体策は未決 | 2026-09-28 | 全モデルに中立な共通レシピはない。「同じ条件」とは、ハイパーパラメータを揃えることではなく、調整にかける手間を揃えて最良どうしで比べること。共通レシピでの結果は参考値として残す。未決：基準にするレシピ（通常学習のレシピを使うか、系統ごとの最適化手法＋学習率の調整にするか）、事前学習との組み合わせ方、代理学習（ImageNet-100）の妥当性の検証。 |
| A3 | 読者と速度評価 | 決定 | 2026-09-28 | 頑健性の研究者向け。投稿先は考えず、最善を尽くす。速度は手元の GPU だけで測る（スマートフォンや Jetson は使わない）。提案：CPU での推論速度も併記し、実機で測っていないことを限界として明記する（未確認）。 |
| A4 | 脅威モデル | 決定 | 2026-09-28 | 当面は ℓ∞ の ε=4/255 だけ。ℓ2 は、人間が最終評価と言ったときに評価だけ行う。ℓ2 での学習し直しは絶対にしない。 |
| A5 | 主題の立て方 | 決定 | 2026-09-28 | 「容量が足りない状況での打ち手」。すぐ実用できるとは主張しないが、限界を示すことに価値がある。「容量不足」は前提にせず、仮説として検証する。どの対策も、同じ計算量でより大きいモデルを使う場合と比べる。 |
