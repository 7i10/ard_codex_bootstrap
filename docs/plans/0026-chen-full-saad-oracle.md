## Question

Can the exact pinned upstream full-SAAD path run safely with the smaller ERT
teacher `Chen2021LTD_WRN34_10`, and does it later recover the gap left by the
controlled entropy-only ablation?

Bartoldson's Plan-0025 No-Go may be specific to its 365.9M-parameter teacher
on a 24GB device.  Chen has 46.2M parameters and a 177-MiB checkpoint.  A Chen
oracle can distinguish teacher-size feasibility from a full-SAAD runtime
failure.  It cannot establish Bartoldson/IRT full-SAAD performance.

## Machine-verifiable teacher contract

A standalone probe loads the pinned RobustBench architecture and exact local
checkpoint in both the established ARD Python and upstream Python.  It uses
four deterministic `[0,1]` CIFAR-shaped inputs generated by an explicit formula
without RNG.  Evidence records input formula/hash, both runtimes, checkpoint,
source, 4x10 FP32 logits and argmax.  Candidate versus reference must satisfy
`rtol=0`, `atol=1e-4` and identical argmax.  The comparison artifact and source
hash are mandatory inputs to every smoke and heavy gate; YAML declarations are
not evidence.

## Bounded smoke and Go gate

Run on physical Hamster GPU 0 with fresh outputs:

1. batch 16 for exactly two finite loss records;
2. batch 128 for exactly ten finite loss records.

Both must have clean/matching Git, command-source/runtime/input/import and
teacher-probe identities; no download, W&B, evaluation or checkpoint is
allowed.  Batch-128 peak memory must be at most 22,500 MiB, temperature below
80 C, telemetry error-free and stable over the final samples.  OOM, identity
drift, non-finite loss or higher peak is terminal No-Go.  Do not change batch,
GPU count, allocator, AMP, attack, objective or threshold after seeing results.

## Heavy-run safety gate

`--mode full --execute` stays fail-closed until all of the following are
machine verified before process creation:

- hash-bound successful batch-16 and batch-128 smoke manifests;
- exact teacher-probe evidence and fixed input/logit contract;
- identical source/runtime/input/import identity and frozen protocol;
- batch-128 peak at most 22,500 MiB and no telemetry error;
- clean current Git SHA and fresh output directory.

Write an immutable `launch-manifest.json` before starting the child.  Persist
heartbeat/progress and GPU telemetry atomically during the non-resumable run;
write terminal state and stdout/stderr/telemetry hashes separately.  A host
failure must leave authoritative launch evidence.  Upstream test-each-epoch,
in-process final AutoAttack, final-SWA-only checkpoint and absence of
best/last/resume remain explicit limitations.
